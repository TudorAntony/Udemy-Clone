# Udemy-Clone

A simple Udemy clone website built using HTML and CSS. This project recreates the basic layout and design of an online learning platform with a clean and responsive user interface.

Features
Homepage design inspired by Udemy
Course sections/cards layout
Navigation bar
Responsive and clean UI
Basic website structure using HTML and CSS

Technologies Used
HTML5

CSS3
Purpose
This project was created to practice front-end web development skills, improve webpage structuring, and learn CSS styling techniques by 
building a clone website.
